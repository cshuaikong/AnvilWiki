### 元数据候选

```json
{
  "home": {
    "meta": {
      "title": "First Person Boxing Wiki — Controls, Counters & KO Guides",
      "description": "First Person Boxing wiki for Roblox players: learn controls, slips, guards, stamina, counters and knockout tactics, with beginner guides and gameplay tips."
    }
  },
  "metadata": {
    "title": "First Person Boxing Wiki — Controls, Counters & KO Guides",
    "description": "First Person Boxing wiki for Roblox players: learn controls, slips, guards, stamina, counters and knockout tactics, with beginner guides and gameplay tips.",
    "keywords": "First Person Boxing, Roblox, controls, slips, counters, stamina, knockout guides"
  }

```

`metadata` 是基础调研提示词要求的**交付结构**；现有项目实际首页使用 `src/locales/en.json` 的 `home.meta`，不能直接新增一个顶层 `metadata` 并期望页面自动读取。上面的攻略覆盖范围是**拟建设内容**；只有对应内页完成后才应用这版 SEO 文案。

### 对应当前首页结构的资料

- Hero 的厂商用 `Can You Box?`，平台用 `Roblox`，类型可写 `First-person boxing / Fighting`；发布日期留空。当前项目的 Hero 基础资料读取 `src/config/site.ts` 的 `site.game`。
- 游戏介绍：**背景**无需编造剧情，可说明这是 Roblox 上的竞技拳击体验；**玩法**突出视角、距离、闪避、反击、防守、耐力；**适合人群**为喜欢对战、练习读招与反应时机的玩家。文案放在 `src/config/editorial.ts` 的 `gameProfile`。
- 开发者简介：只写“Can You Box? 是官方游戏页署名的开发者/发布主体”；团队历史、人数、所在地、旗下其他作品均待官方证据。`developerProfile.games` 先只列本作。
- 游戏更新：以官方游戏页或可证实的开发者公告为准；不要把页面上的“最近更新日期”扩写成未经证实的补丁内容。
- 推荐首批内页入口：新手操作、闪避与反击、防守与耐力、KO/击倒机制。Boss、物品、Tier List 等旧游戏栏目不能仅凭模板保留为本游戏事实。
- Footer `about` 候选："An independent fan guide for First Person Boxing on Roblox. Learn the controls, defensive timing, stamina management, counters, and KO tactics with sourced, regularly reviewed guides."（两句；当前 `footer.about` 实际是“About”导航标签，若要展示简介需使用现有站点介绍字段或调整组件。）
- `sidebarCodes`：目前有两枚站主确认可用的游戏兑换码，展示时注明来源及最后核查日期；不要将媒体来源误写成官方公告。
