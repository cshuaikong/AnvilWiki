## Which First Person Boxing controls should you identify first?

Identify movement, camera control, punches, head guard, body guard, and slips before learning a combat routine. These actions come directly from the official game description. The public listing does not provide a stable key map, so the prompt displayed by the current Roblox client is the authoritative input for your device.

| Control group | Verified purpose | What to check in game |
| --- | --- | --- |
| Movement | Change position during a fight | Current movement input and whether the camera remains controllable |
| Camera | Follow the opponent in first person | Current look input and sensitivity behavior |
| Punches | Attack and create pressure | Every displayed attack input and its animation |
| Head guard | Protect the head area | Prompt, visual state, and stamina response |
| Body guard | Protect the body area | Prompt, visual state, and stamina response |
| Slip | Avoid an incoming punch | Prompt, direction, feedback, and recovery |

The table deliberately excludes keys that have not been verified in the current build.

## How do you verify a control without guessing?

Enter AI practice, read the displayed prompt, perform the action once, and confirm the expected animation or UI response. Repeat the test after changing devices or after an update. A third-party page may correctly describe normal Roblox movement while still guessing the game-specific combat buttons.

Use this four-part record for any future control update:

1. Device and input method.
2. Date and current game update time.
3. Prompt or settings screenshot.
4. Result of performing the input in AI practice.

This evidence is strong enough to update a guide without copying another boxing game’s layout.

## Do PC, mobile, and console use the same combat system?

The official listing names PC, mobile, and console, while the game description presents one set of core mechanics. It is therefore safe to say the experience supports those device categories. It is not safe to claim identical buttons, identical interface placement, or equal performance without testing each platform.

Read the [PC controls guide](/controls/pc/) for keyboard and mouse verification and the [mobile controls guide](/controls/mobile/) for Android and other touch devices. Console inputs remain a pending test because no sourced controller map is available.

## How should you combine the controls during practice?

Learn each input separately, then combine only two decisions at a time. Move while keeping the opponent visible, pair a threatened target with the appropriate guard, and compare a guarded result with a slip. Add an attack only when you can still recognize the stamina and camera feedback.

The [POV guide](/guides/first-person-boxing-pov/) explains what to watch on screen. Continue with [combat basics](/combat/combat-basics/) once the inputs are familiar, or follow the complete [beginner path](/guides/getting-started/).

## Where should changed controls be reported?

Record a changed prompt with a screenshot, date, platform, and short reproduction step. That is more useful than reporting that an old key “does not work,” because it identifies whether the change belongs to Roblox, the game, or a specific device. Until verified evidence exists, this wiki will direct players to current in-game prompts.
