## How to redeem codes in First Person Boxing

1. Open [First Person Boxing on Roblox](https://www.roblox.com/games/132956556682909/First-Person-Boxing).
2. Press **B** or select **Shop** on the left side of the game screen.
3. Enter **FIRSTPERSON**, **SOVIETUPD**, **BALANCEUPD**, **RANKEDUPD**, **LUCK1**, **UPPERCUT**, or **FPSBOXING1** in the code field, one at a time.
4. Select **Redeem** to claim the matching Spin reward.

The Shop route and reward names come from [Pro Game Guides' First Person Boxing walkthrough](https://progameguides.com/roblox/first-person-boxing-codes/). The B shortcut applies to a keyboard; on other devices, use the visible Shop control. If a code fails, check its spelling and spacing first. A code already claimed on the same account or one that has expired will not award another reward.

## What do the rewards do?

The codes award Spins used to roll for fighting styles. **FIRSTPERSON** is listed for one Lucky Spin; **SOVIETUPD** for one Lucky Spin, three Spins, and 1,000 Coins; **BALANCEUPD** for five Spins; **RANKEDUPD** for one Lucky Spin, three Style Spins, and 1,000 Cash; **LUCK1** for five Style Spins; **UPPERCUT** for one Lucky Spin; and **FPSBOXING1** for three Spins. The exact style you receive depends on the game's current roll system, so a code does not guarantee a particular style.

For the fundamentals behind any style, start with the [beginner guide](/guides/getting-started/), review the [controls](/controls/controls-basics/), or learn how [guards, slips, stamina, and counters](/combat/combat-basics/) interact.
